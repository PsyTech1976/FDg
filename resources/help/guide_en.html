📖 FDg User Guide v1.2.0

Application created with AI based on an idea by PsyTech76 - Free & Open

1. What is FDg?

FDg is a modern, responsive, and intuitive graphical interface for the blazing fast Linux search utility fd (packaged as fdfind on Debian and Ubuntu). FDg allows you to instantly locate files and folders anywhere on your system, with full support for MS-DOS style wildcards (* and ?), natural sorting, and seamless desktop integration.

2. How to Search

  1. Search Field: Enter the file name or pattern to look for (e.g. document*.pdf or *report*). The Search button is automatically enabled only when the field contains text.
  2. Starting Folder:
    • Defaults to the root filesystem /.
    • Click the Home button to instantly set your user home directory.
    • Click Browse... to pick any folder using the directory picker.
  3. Additional search parameters (collapsible):

    Clicking the arrow ▶ Additional search parameters expands or collapses the advanced settings panel to keep the interface clean and compact:

    • Hidden files (-H): Search hidden files and directories (names starting with .).
    • Case sensitive (-s): Case-sensitive search.
    • Follow symlinks (-L): Traverse symbolic links.
    • Use wildcards (* and ?): Enabled by default, allows DOS/Glob patterns.
    • Type: Restrict to All items, Files only, or Folders only.
    • Language: Instantly change the user interface language among the 5 supported options.
  4. Click Search or press Enter on your keyboard.

3. MS-DOS Wildcard Patterns (* and ?)

4. Immediate Search Cancellation (Kill App / Process)

Guaranteed Safety and Performance:
When you click Cancel, the background fd process is immediately terminated via SIGKILL.
Why is this 100% safe? The fd utility exclusively performs read-only filesystem scanning. It never writes to, modifies, or deletes files. Forcefully killing it is completely safe for your operating system and documents, while instantly releasing CPU and RAM resources.

5. Results and Actions

  • Double-click File Name: Immediately opens the file using your default desktop application (Kate, VLC, Gedit, LibreOffice, image viewer, etc.).
  • Double-click Path: Opens your system file manager (Dolphin, Nautilus, Nemo, Thunar, PCManFM) and highlights the selected file without opening it.
  • Click Column Header: Sorts results alphabetically and numerically in ascending (A-Z / 0-9) or descending order.
  • Right-click (Context Menu): Options to open file, show in file manager, copy absolute path, or copy file name.

6. Desktop Integration (Menu & Taskbar)

AppImage applications run from temporary mount points. As a result, pinning a running AppImage directly to the KDE Plasma or GNOME panel causes the icon to disappear or stop launching once the application closes.

To solve this permanently, FDg includes an integrated tool under the Tools menu:

  • Integrate into system (Menu & Taskbar)...: Automatically creates a standard desktop entry (fdg.desktop) and high-resolution icon in your user profile (~/.local/share/applications/ and ~/.local/share/icons/). FDg will then appear in your system launcher and can be pinned permanently to the taskbar or dock.
  • Remove system integration...: If you ever want to remove the launcher, the same menu item detects it and uninstalls it cleanly with a single click.

7. Automatic Check & Installation of the 'fd' Engine

To perform its fast searches, FDg relies on the binary search engine fd (packaged as fd-find / fdfind on Debian and Ubuntu).

Smart Startup Check:
When FDg launches, it automatically checks if the fd or fdfind command is available on your operating system.
If the engine is missing, a dialog asks if you would like to download and install it automatically.
  • Automatic Distribution Detection: FDg detects your package manager automatically (Arch Linux with pacman, Debian/Ubuntu with apt-get, Fedora with dnf, openSUSE with zypper).
  • Secure Graphical Authentication: Elevation of privileges is requested securely via the native PolicyKit dialog (pkexec).
  • Live Progress Streaming: During installation, real-time command output is shown in a log viewer with a progress indicator and final confirmation message.
  • Pre-check and Menu Access: via Tools → Check or Install 'fd' engine..., FDg first checks if the engine is already installed and displays its detected version. If already present, it confirms readiness without triggering any redundant installation; only in its absence does it start guided installation.
